## Setup in VS Code

1. Open this `portfolio` folder in VS Code.
2. Put your portrait photo at `images/profile.jpg`.
3. Put your resume PDF at `resume.pdf`.
4. Install the VS Code extension "Live Server".
5. Right-click `index.html`.
6. Select "Open with Live Server".

## Social links

Instagram and LinkedIn are already added in `index.html`.
GitHub is intentionally not included.
